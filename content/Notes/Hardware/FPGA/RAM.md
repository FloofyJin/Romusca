SRAM - Static RAM
Fast, simple, expensive per byte,  volatile

FLASH
Non-volatile memory that stores firmware

DRAM - Dynamic RAM
very dense. Cheap per byte. slower than SRAM. requires refresh cycles

VRAM - Virtual RAM
A type of RAM optimized for graphics operations (framebuffer storage, textures, etc)
usually high bandwidth designed tofeed the GPU with large amounts of data quickly
Can be GDDR (Graphics DDR) like GDDR6 or HBM (High Bandwidth Memory)

While SRAM focuses on speed, VRAM focuses on badwidth/throughput.
